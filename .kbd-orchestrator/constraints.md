## Workflow Triggers

```yaml
workflow_triggers:
  - event: on_iteration_complete
    action:
      type: command
      target: 'bun run typecheck && bun run desktop:typecheck'

  - event: on_change_complete
    action:
      type: command
      target: 'bun run typecheck && bun run desktop:typecheck && (cd server && cargo check) && (cd apps/desktop && cargo check)'
```

No auto-commit trigger: the generic `git add -A && git commit` would sweep other
agents' uncommitted work into the commit, which AGENTS.md forbids. Commit
path-scoped, per `ai/formatting-and-file-size.md`.
